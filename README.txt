IZEL - upload steps
1. In GitHub, open your repo, click Add file > Upload files.
2. Open this unzipped folder, press Select All, and drag EVERYTHING into GitHub, Commit. Then add Add file > Create new file, name it api/index.js, paste api-code.txt, Commit.
3. In Vercel: Framework Preset = Other, leave Build and Output empty. Add the environment variables, then Deploy.
4. In Supabase SQL Editor, paste schema.sql and run it. Create a private storage bucket named izel-media.
